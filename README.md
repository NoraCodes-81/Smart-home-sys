
# Smart Home Automation & Security System 🏠⚡

An integrated IoT Smart Home automation prototype built with Arduino. Designed to optimize home security, environmental monitoring, and automated safety routines.

## 🌟 Key Features
* **RFID Access Control System:** Secure door entry system utilizing RC522 RFID module and Servo motor mechanism.
* **Environmental & Climate Monitoring:** Real-time collection and display of temperature, humidity, and atmospheric conditions via DHT sensor.
* **Sound-Activated Lighting:** Automated indoor illumination control using sound/acoustic sensors.
* **Smart Rain & Clothes Protection:** Automated rack control driven by rain sensors to protect drying clothes from adverse weather.

## 🛠️ Hardware & Tools
* **Microcontroller:** Arduino Board
* **Sensors:** DHT Temperature & Humidity Sensor, Rain/Water Sensor, Sound Sensor, RC522 RFID Reader
* **Actuators:** Servo Motors, LEDs, Breadboards & Jumper Wires
* **Software:** Arduino IDE (C/C++)
